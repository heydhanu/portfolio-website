Log Anomaly Detector

Individual project, November 2026

A Python tool that flags suspicious activity in about 2,000 simulated log entries. It combines a rule (more than 5 failed logins per minute) with an Isolation Forest model, and was tested against injected brute-force and data-transfer spikes.

  • Python
  • scikit-learn
  • Isolation Forest

Credential Verifier

Individual project, November 2026

A Flask web app that issues digital credentials and detects tampering with SHA-256 hash chaining, where each record stores the previous record's hash. A QR-code link opens a verify page that returns VALID or TAMPERED.

  • Flask
  • SHA-256
  • QR codes
